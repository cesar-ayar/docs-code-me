:::tip 🎯 OPTIMIZACIÓN DEL MODELO DE RENDER V6
Para los devoradores de VRAM y modelos de imágenes hiperrealistas (Midjourney v6.0, Stable Diffusion, DALL-E 3), recuerda tatuar siempre al final de tu string el comando de Ratio `--ar 16:9` si el *Output* es para cabeceras Web puras o enormes Presentaciones Deck. Fuerza el `--ar 1:1` exclusivamente si es contenido asfixiado para cuadrado en el Feed nativo de Instagram, o `--ar 9:16` para Reels/TikTok verticales agresivos.
:::
