### 🤖 Generación de Gráficos Asistida (AIO TIP)
No tienes por qué intentar esculpir en 3D un circuito desde cero. Para que el estilo troncal técnico de Code-Me sea **perfectamente legible y procesable** por Inteligencias Artificiales generadoras de imágenes vanguardistas (Como _Midjourney V6_ o _DALL-E 3_), nuestra investigación arroja que siempre deberás asegurar el uso rígido de los siguientes metadatos descriptivos (prompts) en tu petición, como si fueran parámetros fijos de una función.

```bash
# RECOMENDED CORE METADATA CONSTANTS:
--style: raw
--aesthetics: "Cyberpunk Mexico", "neon pink and cyan glow accents"
--components: "retro-tech hardware", "blueprint diagrams and labels"
--rendering: "voxel art elements", "high contrast shadows" 
--theme: "dark mode ui aesthetics"
--ar: 16:9
```

:::info CHECK EL BANCO
Si buscas prompts completos ya estructurados, no olvides visitar nuestra sección matriz en la [Librería de Prompts](/docs/ia/banco-prompts).
:::
