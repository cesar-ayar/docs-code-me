### ☕ Comportamiento Visual (`Z-index: -1`)
- **Nivel de Ruido:** Medio (Ambiental).
- **Tratamiento Gráfico:** Letras sueltas exclusivas del código (`< > { } / ; * =`) o puras palabras reservadas de funciones, dispersas casi caóticamente como si flotaran despresurizadas sin gravedad en el fondo del gráfico.

### ⚙️ Configuración del Sistema (Specs)

**Tipografía Base:** Estrictamente fuentes monoespaciadas legibles por sistema. (*Ej. JetBrains Mono o Fira Code*).
**Variación (Math.random):** Rotación y escala sumamente leve, no debe molestar a la vista al rotar. Solo lo suficiente para crear capas de *Parallax*.

**Materiales RGB Aprobados:**
